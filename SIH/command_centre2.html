Analytics Methodology

How each metric is calculated

Transparent, rule-based calculations used by this prototype. Values change whenever the underlying operational data changes.

FORMULAS
SOS Requests
Total = all SOS records
Pending = status = Pending
Assigned = status = Assigned
Active = status not in {Rescued, Completed}
Changes when SOS records are added or their status changes.
Rescue Missions Completed
Completed missions = count(status ∈ {Rescued, Completed})
Increases when a rescue mission reaches Rescued or Completed.
Average Response Time
Average response = Σ(acceptedAt − createdAt) / N
Uses recorded acceptance timestamps; the prototype baseline is used only when no timestamp exists.
Shelter Occupancy
Occupancy % = ((Total Beds − Available Beds) / Total Beds) × 100
Changes when available beds or total shelter capacity changes.
Resource Consumption
Consumed = Total Stock − Available Stock
Changes when resources are allocated.
Severity Distribution
Count of SOS records grouped by {Critical, High, Moderate, Low}
Changes when an SOS priority changes or a new SOS is added.
AI Predicted Risk by Area
Overall Risk = 32(Rain/300) + 26(River/150) + 16(Soil/100) + 16((100−Drainage)/100) + 10(History/100)
Each area then applies its local profile and disaster-type multipliers. The chart shows the top five calculated area scores.
Change vs prior = current published AI risk score − previous published AI risk score. Positive = risk increased.Negative = risk decreased. First prediction = no earlier published prediction exists, so there is no valid comparison baseline.
